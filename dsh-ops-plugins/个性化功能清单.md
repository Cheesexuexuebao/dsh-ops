# 运维智能体 — 个性化功能清单

相对官方 DeepSeek Harness（DSH）Web，本产品的定制分为两层（现已同仓）：

| 位置 | 路径 | 内容 |
|------|------|------|
| 旁路插件目录 | `deepseek-harness/dsh-ops-plugins/` | SSH 运维能力、工作区策略、皮肤与 UI 屏蔽 |
| Harness 分叉改动 | 同仓 `packages/`、`apps/web` 等 | 品牌资源、SSH 传输层、局域网特权 API |

下文按**功能**列出：**新增了什么** / **屏蔽或锁定了什么**。

---

## 1. 产品品牌与外观

### 新增

- 产品名「**运维智能体**」：Logo / Wordmark、页面标题、favicon、PWA manifest（Harness 内 `FishLogo`、`BrandWordmark` 等）。
- **青色科技风皮肤**（`ops-skin`）：固定暗色青调色板（底色约 `#07151c`）、IBM Plex 字体、Token 覆写。
- **启动页同色防闪屏**：Host 注入 boot CSS；Web `index.html` / `AppRoot` 启动底色对齐，避免先白后青。

### 屏蔽 / 锁定

- 设置里整块「**外观**」（含浅色/深色/跟随系统）：不展示、不可切换；强制暗色。
- 会话列表「**视图选项**」：不展示；侧栏强制 **单列表（flat）**，不按工作区分组。

---

## 2. 固定运维工作区

### 新增

- 固定工作区目录：`~/.dsh/dsh-ops`，标题「**运维**」（`ops-workspace` Host 保证目录存在）。
- 启动时优先进入该工作区；「新会话」钉在运维工作区；已有会话则恢复最近非归档会话，不盲目新建空白会话。

### 屏蔽 / 锁定

- 客户端隐藏「**添加工作区**」（Host 的目录选择能力仍保留，不对外暴露添加入口）。
- 产品定位为**锁定运维台**，不以多工作区扩展为主。

---

## 3. 关闭「自扩展」与模式创作

### 屏蔽 / 锁定（`ops-workspace` patch）

| 插件 / 配置 | 作用 |
|-------------|------|
| `cordis-host-runner` / `cordis-client-runner` | 禁用：动态 Cordis 插件运行时 |
| `ui-cordis` | 禁用：浏览器内 Cordis 面板 |
| `ui-agent-preset` | 禁用：模式芯片 / 设置里的预设名单 UI |
| `agent-presets.default = standard` | 新会话固定 **标准** 模式 |
| `agent-presets.includeUserRoot = false` | 不读用户自建 `~/.dsh/.agent-presets` |

→ 用户无法在产品内动态装插件、切「创造」等自扩展模式；组合由部署侧写死。

---

## 4. 权限与访问模式

### 新增 / 默认

- Host 启动时把默认权限写成 **`workspace-write`**（`ops-skin`）。

### 屏蔽

- 插件 `ui-permission`：**禁用**（设置里改权限的官方 UI）。
- 客户端再藏：访问模式 chip（「访问模式」/ Access mode）、设置「权限」相关行（兜底）。

---

## 5. 引导与对话输入栏

### 屏蔽

- 「**内测声明**」欢迎弹窗：Host 预写已接受版本；Client 隐藏并自动点「继续」，局域网打开也不卡死。
- 对话输入栏左下角「**+** / 命令」按钮（Commands）：CSS 隐藏，减少 slash 命令入口干扰。

---

## 6. 局域网访问（运维台部署）

### 新增 / 改动

- Web 监听 **`0.0.0.0`**（`ops-workspace` 改 `webserver.host`；官方 CLI `--host 0.0.0.0` 仍会拒绝，故用组合 patch）。
- 启动日志仍会打印 `127.0.0.1` 与推导出的 LAN URL；LAN IP 进入 `trustedHosts`。
- Harness `dsh-client-connection`：特权 API（如 `settings.describe`、凭据、模型发现等）对 **`trustedHosts` 与回环同等放行**，否则用局域网 IP 打开页面会配置面 403、表现为「IP 打不开」。

### 说明（非屏蔽，安全边界）

- 仍无完整登录鉴权：能打开页面的人即可驱动本机 Agent/工具；仅适合可信局域网。
- 打印的 `172.x` 有时是虚拟网卡；其他电脑请用真实网卡 IP，并放行防火墙端口。

---

## 7. SSH 运维能力（核心新增）

依赖 Harness 内 **`packages/ssh/`**（传输 seam + `ssh2` 提供方），能力插件在旁路仓：

### 7.1 SSH 连接与资源（`ssh-connection`）

- 挂载 SSH 传输；**设置 → SSH 资源** 管理主机/分组。
- 连接 / 断开；侧栏当前连接；为 ops / monitor 提供 `ctx.ssh`。

### 7.2 SSH 运维面板（`ssh-ops`）

| 能力 | 说明 |
|------|------|
| 交互终端 | 右侧 xterm，可调宽 |
| Agent 工具 | `ssh_exec` / `ssh_read` 等；输出脱敏 |
| 文件（SFTP） | 浏览/上传下载/建删改名；对话工具 `sftp_*` |
| 端口转发 | 本地 / 远程隧道；`tunnel_*` |
| 数据库 | MySQL / PostgreSQL / Redis / MongoDB；查询与结果表；可经 SSH 隧道；高危 SQL 拦截 |
| 安全策略 | 明显破坏性命令拦截，需人在终端手敲 |

### 7.3 SSH 监控（`ssh-monitor`）

- 经当前 SSH 只读采集远端概览、进程；Docker 容器列表/状态（Engine API over SSH）。
- 侧栏「SSH 监控」；无 sock/`curl` 时优雅降级。

| 功能 | 主要落点 |

## 9. 一览表（新增 vs 屏蔽）

| 功能域 | 新增 | 屏蔽 / 锁定 |
|--------|------|-------------|
| 品牌外观 | 运维智能体品牌、青色素、防闪屏 | 外观设置、主题切换 |
| 工作区 | 固定 `~/.dsh/dsh-ops` | 添加工作区入口；非 flat 视图 |
| Agent / 插件 | — | 动态 Cordis、模式选择、用户自建 preset |
| 权限 | 默认 workspace-write | 权限设置 UI、访问模式切换 |
| 引导 / 输入 | — | 内测声明；命令「+」 |
| 网络 | `0.0.0.0` + LAN 可配配置面 | （官方默认仅本机；本产品主动放开） |
| SSH | 连接、终端、SFTP、隧道、库、监控 | — |
